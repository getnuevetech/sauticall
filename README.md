# SautiCall

Public site, customer account, and admin control panel for the Clear White design.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Admin sign-in is at http://localhost:3000/account/login

- Email: `admin@sauticall.test`
- Password: `SautiCall-Admin-2026`

From Admin, edit page copy, navigation, plans, fonts, colors, images, feature switches (including MFA), and payment gateways. The approved design is the default. Leave theme values unchanged to keep it.
